# Hybrid-QCNN-Diabetic-Retinopathy
Official PyTorch and PennyLane implementation of a Hybrid Quantum-Classical Neural Network combining ResNet-50, residual 1D-Conv filter re-weighting, and a dual-basis 4-qubit VQC (CZ+CNOT+U3) for multi-class Diabetic Retinopathy staging on APTOS 2019 (80.22% ± 0.74% 5-seed accuracy, 0.8663 QWK, 96.64% Referable DR sensitivity).
