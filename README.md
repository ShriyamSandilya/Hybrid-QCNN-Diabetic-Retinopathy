This repository provides the official PyTorch and PennyLane implementation for "Hybrid Quantum-Classical Neural Network with Layer-Wise Filter Re-Weighting for Multi-Class Diabetic Retinopathy Staging," evaluated on the APTOS 2019 Blindness Detection dataset. The architecture combines an ImageNet pre-trained ResNet-50 feature extractor with a residual 1D convolutional filter re-weighting block and a 4-qubit Variational Quantum Circuit (VQC) featuring dual-axis angle encoding, cyclic Controlled-Z and stride-2 CNOT entanglement, universal U3 rotations, and dual-basis Pauli-Z/Pauli-X expectation pooling, achieving an 80.22% ± 0.74% five-seed accuracy (81.74% primary-seed peak) and 0.8663 ± 0.0161 Quadratic Weighted Kappa alongside 96.64% sensitivity and 0.9621 ROC-AUC for Referable Diabetic Retinopathy screening.
